# CarSim–Simulink漂移与固定路径跟踪实验

本项目搭建车辆漂移动力学仿真平台，通过逐阶段实验验证控制方法。当前已完成三步：**普通直行起漂并维持 → 完整退出并恢复直行 → 沿固定操场路线连续完成两个漂移弯。**

当前 `main` 对应 **V0.3五状态反馈基线**。已验收漂移目标为 **12 m/s、β=−10°、AVz=0.6 rad/s**，名义稳态半径20 m。以下结果来自CarSim–Simulink联合仿真，不是实车试验或任意漂移工况能力证明。

## 控制方法

控制由**阶段与工作点调度 → 五状态局部反馈 → 转角/滑移请求 → 公共执行层 → CarSim车辆**组成。

- 连续反馈：车速 `V`、质心侧偏角 `β`、横摆角速度 `AVz`、前轴平均滑移率 `κf`、后轴平均滑移率 `κr`，增益矩阵为 `3×5`。
- 反馈输出：前轮目标角、前后轴目标滑移率；前轮采用左右相同转角的平行转向假设。
- 执行层：根据实际接地点速度生成轮速目标，使用实际纵向轮胎力 `Fx` 补偿负载，并保留轮惯量项、轮速变化约束、完整力矩预算和转向限速。
- 车辆侧：使用当前CarSim查表轮胎、组合滑移、松弛和悬架模型，实际四轮轮荷参与分配。Roll、AVx保留在物理动力学、监测和接管判断中，不进入上述连续增益乘法。

局部反馈增益来自局部模型的设计。它与原路径LQR是两个控制层；原路径LQR和式4.10路径项在本次验收中关闭。当前成功执行支路直接控制转角和滑移率，不由Fiala轮胎反演驱动。

![当前实际控制结构](docs/v0.3/figures/00_系统结构.png)

V0.3路径外层使用横向与行进方向误差修正横摆参考，限幅±0.03 rad/s、变化率±0.06 rad/s²，借助已有局部反馈协调转角和滑移率。反馈与阶段调度0.01 s，CarSim及转向执行0.0005 s。本次ASB模式为 `baseline`，附加悬架力为零；这里不提供ASB性能结论。

## 如何运行与查看证据

原机验收环境为Windows、MATLAB/Simulink R2023a、CarSim2020.0，使用已设置的GUI数据集及12输入/76输出接口。CarSim就绪后，将MATLAB工作目录切到 `model`：

```matlab
repair_run_mode = 'drift_stadium'; % drift_entry：V0.1；drift_cycle：V0.2
asb_case = 'baseline';
a001_new_Design_LQR_Controller;
open_system('stabilizer_bar_repair');
out = sim('stabilizer_bar_repair','StopTime',num2str(t_final));
```

初始化只准备参数，`sim` 才启动仿真。V0.1运行30 s，V0.2/0.3运行40 s。下载到其他机器后需要处理原机绝对路径、车辆数据库和许可，尚未验证跨机器直接运行；先读[运行说明](docs/运行说明.md)。

## 已验证范围与下一步

本次验证限于当前车辆、路面、初值和三个给定工况。V0.3短稳定弧不能代替长时间维持；两个弯不构成两次独立重复。过渡速度存在波动，V0.3全程峰值12.953 m/s。CarSim弹簧、悬架/轮胎表端外推警告继续记录，未扩表，不能把表外响应当作表内物理验证。

后续先增加固定路线下的偏差与扰动检验，再为其他速度和半径求解、校核工作点，最后组合复杂路线。目前不声称多半径、右转或任意道路漂移已实现。
