# V0.3 从哪里开始

当前默认模式为 `drift_stadium`，仅在原机 Windows、MATLAB/Simulink R2023a 与 CarSim2020.0 环境验收。

1. CarSim 继续使用当前 GUI 数据集和已导出的 sim；本包不生成车辆配置。输入为12路，输出为76路，追加四路悬架力在 baseline 下为0。
2. 关闭其他同名模型，将 MATLAB 工作目录切到本包 `model`。
3. 初始化选择工况，再启动模型。初始化脚本本身不会运行车辆。

```matlab
repair_run_mode = 'drift_stadium';
asb_case = 'baseline';
a001_new_Design_LQR_Controller;
open_system('stabilizer_bar_repair');
out = sim('stabilizer_bar_repair','StopTime',num2str(t_final));
```

`drift_entry` 运行30s；`drift_cycle` 与 `drift_stadium` 运行40s。本包保留普通 `normal` 模式及 `drift_turn` 研究模式，但本次发布验收范围仅为已给出的三版工况，不为其他模式增加性能结论。

连续局部反馈误差只有 V、beta、AVz、kappa_f、kappa_r，矩阵为3×5。Roll 与 AVx 仍用于物理状态记录和原接管门控；不会从车辆模型中删除侧倾。

控制0.01s，CarSim与转向执行0.0005s；左右前轮平行转向，转角/转角速度按deg/deg/s输入；四轮轮矩FL/FR/RL/RR顺序不变。

配置快照在 `config`，实际调用的仍是原机绝对路径。GUI重新导出仅改变 File created 时间说明时可解析；实质配置改变时需核实新配置与工作点的适用性。不要用跳过校验代替重新验证。

`validation` 保存每版实际仿真的未平滑原始 MAT、CarSim log/echo、使用参数和指标。图表只是子采样显示，验收使用原始时间序列。表端警告照常记录，不扩表、不自动终止，并不把外推解释成表内验证。
