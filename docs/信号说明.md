# 五项局部反馈与日志通道

反馈状态 `x_f=[V,beta,AVz,kappa_f,kappa_r]`，单位依次为m/s、rad、rad/s、1、1。局部输入请求为前轮角rad、前轴纵滑与后轴纵滑。

CarSim保留完整车辆模型和四轮查表轮胎，包括组合滑移、松弛、悬架及载荷转移。控制支路由冻结工作点前馈和五项局部反馈产生角度/滑移请求；Fiala及动力学逆解只作保留的诊断，原路径LQR与式4.10不参与三个漂移模式的执行。

原50路物理测量经76路接口选择后保持原顺序。`repair_plant_raw` 的50项：1 Vair，2 Vx(km/h)，3 Vy(km/h)，4 Beta(deg)，5 AVz(deg/s)，6 Ax(g)，7 Ay(g)，8 Roll(deg)，9–12 Fx(FL/FR/RL/RR,N)，13–16 Fy(N)，17–20 Fz(N)，21–24轮速rpm，25 Pitch(deg)，26 AVx(deg/s)，27–30纵滑，31–34侧偏角deg，35–36 Xcg/Ycg(m)，37 Yaw(deg)，38–41车轮转角deg，42–45 My_Dr(Nm)，46–47 Xo/Yo(m)，48–50原诊断量。

`repair_actuator_command`：前两项为左右前轮角deg，第3–4项为对应deg/s，第5–8项为FL/FR/RL/RR轮矩Nm。

`repair_entry_diag` 共70项：1–8阶段/进度/接管与准备标志；9–15实际七项物理状态；16–22名义七项物理参考；23–25输入前馈；26–28反馈后请求；29–31约束后请求；32–35候选轮速；36–39执行目标轮速；40–43实际轮速；44–47轮速反馈力矩；48–51惯量力矩；52–55实际Fx负载补偿与偏置；56–59保护前力矩；60–63最终力矩；64–66请求约束、轮速投影、最终保护标志；67–70接地点速度。

`feedback_diag` 共17项，含义在本发布中固定：1反馈维数=5；2–7两项直接侧倾反馈贡献=0；8–10名义前馈请求；11–13实际反馈后请求；14–17平面状态、侧倾、接地及总阶段失败标志。`asb_roll_feedback` 六项为零，保留端口兼容，不能解释为另一个控制器的输出。

`repair_cycle_diag` 共16项：阶段、退出进度、子阶段、维持时间、维持门控、接管范围、直行接管计时、混合权重、退出距离，以及七项物理参考导数。`repair_stadium_diag` 共17项：空间进度、弯编号、阶段、横向误差、速度方向误差、原/限后横摆修正、名义/修正横摆参考、限幅/限速标志、局部XY、参考方向、响应增益、圈完成和阶段失败。

所有原始日志含独立时间轴；不要将0.01s控制记录误认为0.0005s车辆记录。
