# CarSim–Simulink车辆漂移研究

当前版本 **V0.5：±30°左右连续漂移与五种辅助侧倾刚度对照**。

从普通直行初态完成：**左−30°漂移→固定10 s维持→连续换向→右+30°漂移→固定10 s维持→退漂→自然直行**。五种配置均完成60 s并通过原状态验收。

本版回答两个问题：同一冻结控制器能否完成双向任务；不同辅助侧倾刚度在哪些阶段改变响应，又付出什么代价。自然轨迹形成左右双环，但不考核指定八字路径、交叉点或位置闭合。

## 五组结果：快慢随阶段变化

单位：前/后内部Auxiliary Roll系数为N·m/deg，时间为s。耗时取对应阶段开始至持续合格段起点。

|前/后系数|左起漂|换向至右漂|最终恢复|换向最低轮荷 N|结果|
|---|---:|---:|---:|---:|---|
|384/384|3.7625|9.6060|6.4930|799.41|PASS|
|192/384|3.5420|9.5760|6.4760|825.73|PASS|
|576/384|4.0575|9.6265|6.5055|859.40|PASS|
|384/192|4.7650|9.7510|6.4630|1188.32|PASS|
|384/576|3.4695|9.5320|6.5130|452.91|PASS|

**后硬384/576较早进入左右漂移，但最低轮荷更低；后软384/192进入较慢，最终恢复却最快。**最终恢复极差50 ms，起漂极差1.2955 s。不同阶段的控制调度和初态不同，不能把这些差值解释为固有敏感度，也没有全过程最优配置。

## 相同控制器怎样作用

五状态[V,β,AVz,κf,κr]反馈产生转向及前后滑移请求，公共执行层保留Fx补偿、轮惯量、限速、轮速预算与±3000 N·m轮矩预算。参考、前馈、3×5增益与轮矩偏置同步调度：起漂2.5 s、换向29/3 s、最终退漂43/6 s。五组不重新配平或调增益，但实际转向和轮矩允许随反馈变化。

目标速度12 m/s，左/右β为−30°/+30°，车体AVz约+0.598980/−0.598986 rad/s。控制0.01 s、车辆及原生记录0.0005 s，12输入/76输出。无路径反馈，四路外部ASB恒零。

## 为什么先处理道路异常

上批两组在道路XY→S/L坐标查询时中断。旧参考线是15 m圆，报错点距圆心仅15—19 cm。独立研究配置改用直线道路坐标，物理平面、μ=0.85、车辆和控制保持。

**旧三组完整60 s、旧两组全部有效前缀，各56个数值通道均与新运行逐位一致。**新五组全部跑完。因此旧中断不能用作刚度导致失控的证据；没有把历史失败藏掉，也没有通过调控制器得到通过结果。道路参考直线不等于让车辆直线行驶。

[道路诊断、配置差异与完整回归证据](docs/v0.5/report.md#1-原因物理路面与道路参考线不是一回事)

## 固定刚度与主动ASB分开看

本版是固定内部系数对照，Kaux不是整轴总侧倾刚度；不能称主动ASB控制已验证。V0.4另有单轴±250 N·m主动起漂试验，其局部方向与代价见[V0.4综合报告](docs/v0.4/report.md)。主动脉冲没有加入V0.5，也未证明换向或退漂主动控制收益。

后簧及其他查表外推仍存在，报告保留幅度与时长。结果仅覆盖当前CarSim参数和既定外推、当前任务及控制预算，不作为实车机械安全、普遍最优刚度或能力边界结论。
