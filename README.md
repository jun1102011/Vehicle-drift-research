# V0.3｜固定操场路线的双弯漂移跟踪

本版将V0.2的起漂、维持和退出能力用于一条固定操场路线，新增空间阶段调度与小幅路径纠偏。**40 s联合仿真完成一圈两直线、两左转漂移弯；全圈横向误差RMSE为0.0980 m，两弯稳定段拟合半径分别为19.913 m与19.962 m。**

本版的进展是从“自由形成轨迹的状态控制”走向“仿真前固定路线的跟踪”，仍围绕同一个20 m漂移工作点。

## 实验设计与相对V0.2的变化

| 项目 | 设置 |
|---|---|
| 闭合路线 | 两条60 m直线、两个左转漂移弯；一圈参考长度约320.05 m |
| 引入段 | 与首直线共线的80 m准备段，位于计圈路线之外 |
| 稳定漂移目标 | V=12 m/s、β≈−10°、AVz≈0.6 rad/s、名义半径20 m |
| 弯道处理 | 保留入漂和退出的平滑过程；20 m约束对应稳定段，不把整个弯当作严格半圆 |
| 新增外层 | 固定路径投影、空间阶段调度、横向与速度方向误差纠偏 |
| 纠偏幅值 | 横摆参考修正±0.03 rad/s，变化率±0.06 rad/s² |

参考路线在正式试验前冻结，只在仿真开始按初始质心位置与方向整体对齐。控制根据实际质心位置、行进方向与连续路线进度纠偏；不会在验收后移动圆心或重新拟合参考来减小误差。两个弯共用执行器历史，不恢复配平快照。

本版以有限弯道的空间阶段调度取代V0.2的10 s漂移保持阶段；起漂和退出参考需在弯道内完成。原路径LQR及式4.10路径项继续关闭，小幅横摆修正通过现有局部反馈进入执行层。

## 控制方法

控制由**阶段与工作点调度 → 五状态局部反馈 → 转角/滑移请求 → 公共执行层 → CarSim车辆**组成。

- 连续反馈：车速 `V`、质心侧偏角 `β`、横摆角速度 `AVz`、前轴平均滑移率 `κf`、后轴平均滑移率 `κr`，增益矩阵为 `3×5`。
- 反馈输出：前轮目标角、前后轴目标滑移率；前轮采用左右相同转角的平行转向假设。
- 执行层：根据实际接地点速度生成轮速目标，使用实际纵向轮胎力 `Fx` 补偿负载，并保留轮惯量项、轮速变化约束、完整力矩预算和转向限速。
- 车辆侧：使用当前CarSim查表轮胎、组合滑移、松弛和悬架模型，实际四轮轮荷参与分配。Roll、AVx保留在物理动力学、监测和接管判断中，不进入上述连续增益乘法。

局部反馈增益来自局部模型的设计。它与原路径LQR是两个控制层；原路径LQR和式4.10路径项在本次验收中关闭。当前成功执行支路直接控制转角和滑移率，不由Fiala轮胎反演驱动。

## 实验结果

固定计圈窗口为 **7.00—33.58 s**；图中的全程起终点不等于这个闭合窗口的起终点。

| 全圈验收量 | 本次结果 | 工程门槛 |
|---|---:|---:|
| 横向路径误差RMSE | 0.0980 m | ≤0.5 m |
| 横向路径误差峰值 | 0.2041 m | ≤1 m |
| 返回固定截面的位置差 | 0.2055 m | ≤1 m |
| 返回固定截面的行进方向差 | 0.1828° | ≤3° |
| 路线切换失败 | 未发生 | 不允许发生 |

| 稳定漂移段 | 弯1 | 弯2 |
|---|---:|---:|
| 验收窗口 | 14.80—16.64 s | 28.10—29.94 s |
| 窗口时长 | 1.84 s | 1.84 s |
| 拟合半径 | 19.913 m | 19.962 m |
| 实际稳定圆弧 | 63.43° | 63.26° |
| 车速RMSE | 0.00597 m/s | 0.00683 m/s |
| 侧偏角RMSE | 0.11255° | 0.08764° |
| 横摆角速度RMSE | 0.00389 rad/s | 0.00199 rad/s |

两弯分别通过车速≤0.2 m/s、侧偏≤2°、横摆≤0.03 rad/s的RMSE门槛、半径相对20 m偏差≤2%及稳定圆弧≥60°的要求；两段直线也通过其状态门槛。全程轮矩绝对峰值1286.1 N·m，最终力矩保护未触发。全程车速为8.333—12.953 m/s，过渡速度波动单独记录。

## 如何查看与复现

先看本页的轨迹、状态曲线和结果表，再查[完整验收报告](docs/v0.3/验收报告.md)、[指标JSON](validation/v0.3/version_metrics.json)和[原始MAT](validation/v0.3/raw.mat)。指标由未平滑原始数据计算；图片仅按0.01 s间隔取点显示。

原机验收环境为Windows、MATLAB/Simulink R2023a、CarSim2020.0。先使CarSim当前GUI数据集就绪，再在MATLAB中切到仓库的 `model` 目录执行：

```matlab
repair_run_mode = 'drift_stadium';
asb_case = 'baseline';
a001_new_Design_LQR_Controller;
open_system('stabilizer_bar_repair');
out = sim('stabilizer_bar_repair','StopTime',num2str(t_final));
```

本版运行40 s，控制周期0.01 s，车辆及转向执行周期0.0005 s。初始化脚本只准备参数，`sim` 才启动车辆。接口为12输入/76输出；本次 `baseline` 的四路附加悬架力为零。仓库含原机绝对路径与配置快照，尚未验证下载后在其他机器直接运行。详细设置见[运行说明](docs/运行说明.md)。

`model/` 保存核心模型、唯一初始化入口和冻结工作点；`config/` 保存CarSim配置快照；`docs/` 保存报告与图；`validation/` 保存原始数据、运行日志与验收指标。文件哈希见 `MANIFEST.sha256`，`.gitattributes` 保留原样字节。

## 结果边界与后续实验

每弯的1.84 s窗口用于本次有限路线验收，不能替代长时间漂移维持；同一圈的两个弯也不是两次独立重复。当前证明的是固定车辆在这条冻结路线、单一20 m工作点附近完成双弯漂移，不代表多半径、右转、连续换向或广泛鲁棒性已经验证。

悬架及轮胎数据的表端外推警告仍存在，未扩表，不把表外结果解释为表内物理验证。后续应逐项增加偏差/扰动试验，再求解和验证其他速度、半径工作点，最后组合成复杂路线。
